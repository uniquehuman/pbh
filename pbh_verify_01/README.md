# PBH-VERIFY-01 — пилот «вывод → реализация → независимая проверка» для модуля сферических 3+1-диагностик

**Что это.** Небольшой воспроизводимый эксперимент ТЗ `../pbh_computational_physics_agent_prompt_ru.md`: модуль `sphdiag` вычисляет по сферическому срезу (A, R, K^r_r, K^θ_θ) и материи (скалярное поле φ, Π или Vlasov-моменты) проекции T_ab, невязки связей, массу Misner–Sharp, световые расширения θ±, классы сфер и кандидаты apparent horizon — с оценками численной ошибки и статусами пригодности. Он **не** эволюционирует данные и **не** решает связи. Выводов о f_PBH, EKG→Vlasov или космологическом сценарии пилот не делает.

## Результат одной строкой

Модуль (`impl-B-v0.5`, контракт v1.4) проходит 34 из 35 тестов независимой матрицы v2 (провал U62 — неустранимый по одному снимку компромисс между ложной тревогой и пропуском недоразрешённости). Все 13 предрегистрированных мутантов убиты и разработческими тестами, и замороженными независимыми матрицами. Аудит нашёл все 4 тайно внесённых кодовых дефекта и частично — круговой тест. Естественные ошибки найдены в контракте (14 шт., одна — неверный знак в F10), в численной логике реализации (не в формулах) и в допусках самой проверки. Самая содержательная находка получена на реальных данных V1: первый горизонт V1 ставится на ядре шириной в одну ячейку, где знаки θ± не разрешены (см. `decision.md`).

## Зависимости

Python 3.12.3, numpy 2.5.3, scipy 1.18.1, pytest 9.1.1 (системные). sympy 1.14.0 + mpmath 1.3.0 — только для `derivation/` и части эталонов; ставятся локально:

```bash
pip install --target .pydeps sympy==1.14.0
```

## Команды

Разработческие тесты:

```bash
cd /root/PBH/pbh_verify_01 && PYTHONPATH=src python3 -m pytest tests/dev -q
```

Независимая матрица (≈ 1–4 мин):

```bash
cd /root/PBH/pbh_verify_01 && SPHDIAG_PATH=src python3 tests/independent/run_matrix.py --out results/matrix_now.json
```

Та же матрица на реализации A:

```bash
cd /root/PBH/pbh_verify_01 && SPHDIAG_PATH=arch_A/src python3 tests/independent/run_matrix.py --out results/matrix_A_now.json
```

Символьная проверка формул:

```bash
cd /root/PBH/pbh_verify_01 && PYTHONPATH=.pydeps python3 derivation/core.py
```

Мутанты (генерация, затем dev-набор и замороженная матрица; замороженная копия матрицы — `git archive verify-matrix-v2 tests/independent independent_reference | tar -x -C <dir>`):

```bash
cd /root/PBH/pbh_verify_01 && python3 mutants/make_mutants.py --out mutants/v0.4
```

```bash
cd /root/PBH/pbh_verify_01 && ./mutants/run_dev_on_mutants.sh mutants/v0.4 results/mutants_dev_v0.4code_v0.4suite.txt
```


## Ограничения

См. `decision.md` (разрешено/заблокировано) и `audit_report.md` §6. Главные: оценка ошибки по одному снимку не видит изломов (нужна сходимость на двух сетках); погрешности входных полей не принимаются; касательные нули не ищутся; все роли — экземпляры одной модели, поэтому общая ошибка возможна (пример — одинаковый ложный VIOLATED у A и B, N13).
