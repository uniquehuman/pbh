# Сравнение архитектур A и B (ТЗ §10)

Одинаковые условия: контракт v1.0, одна машина, одна модель, одна внешняя матрица (v1 заморожена до первого прогона). Не выровнено: A получил контракт v1.0 уже с исправлениями роли derivation (Р1–Р7), то есть часть работы B досталась A бесплатно.

| Мера | A: один агент + самопроверка | B: derivation / implementation / audit / verification |
|---|---|---|
| Токены субагентов | 278 тыс. | ≈ 1.6 млн (derivation 230 тыс., реализация 247 тыс. в раунде 1 и 378 тыс. за 5 раундов, аудит 189 тыс., верификация 482 тыс.) |
| Время до первой сдачи кода | 40 мин | 25 мин (реализация), плюс 21 мин derivation до неё |
| Независимая матрица v1 (29) | 27 PASS; оба FAIL — дефекты допусков матрицы | 28 PASS; FAIL — дефект допуска матрицы |
| Матрица v2 на коде по контракту v1.0 (35) | 26 PASS | 26 PASS (B v0.1) |
| Ложный VIOLATED на гладких данных (U62) | да | да (тот же) |
| Уникальные находки | чувствительность к шуму у касательной сферы (N10) | знак F10 в черновике (derivation; A его тоже нашёл, но на уже исправленном контракте), зависимость от ориентации r (аудит; A тоже), UNRESOLVED-ядро на данных V1 (координатор) |
| Зарегистрированное вмешательство человека | не логировалось | не логировалось |

Вывод: архитектура B опробована, но её преимущество над A **не измерено**. На внешней матрице исходы неразличимы. Обе реализации совершили одну и ту же ошибку. Большинство существенных находок B сделаны ролями, которые проверяют контракт и реальные данные, а не код. Отдельный результат B, недоступный A по построению, — тайные дефекты: аудит нашёл 4 из 4 кодовых и частично круговой тест. Один модуль и одна модель не позволяют обобщать.
