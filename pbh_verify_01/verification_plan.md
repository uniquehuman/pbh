## 1. Принципы

1. **Эталон никогда не вычисляется функциями проверяемого модуля.** Ожидаемые значения — замкнутые формулы (выведены здесь, §2, и проверены символьно из 4-метрики в `independent_reference/derive_sympy.py`), собственный интегратор FKG, собственный решатель связей-ОДУ, собственные аналитические производные (sympy). Из контракта используется только API (§10) и **имена** классов/статусов (§7, §9) — как спецификация выходов, не как источник чисел.
2. **Нет циклических проверок.** Пример запрещённого: вычислить K_A из импульсной связи функциями модуля и проверить, что модуль даёт 𝓜 = 0. Здесь данные строятся моим ОДУ-решателем в форме «массовой функции», а модуль проверяет их через ³R-форму [F7–F9] с конечными разностями; совпадение нетривиально (разные формы уравнений, разные дискретизации).
3. **Допуски выводятся, а не назначаются.** Три типа:
   - **Округление:** `FLOOR(Q) = 100·ε·S_Q·(L/h_min)^d`, ε = 2.22·10⁻¹⁶, S_Q — физический масштаб величины (указан в тесте), L — длина области, h_min — минимальный шаг, d — число радиальных производных в Q (0 для алгебраических, 1 для M, Rθ±, 𝓜, 2 для 𝓗, 𝓗_M). Обоснование: 5-точечный вес первой производной имеет Σ|w| ≈ 1.5–4/h; каждая производная умножает ошибку округления на ~L/h; множитель 100 — запас на суммирование и разные порядки операций.
   - **Усечение:** `TOL_TR(Q) = 10·E_ref(Q) + FLOOR(Q)`, где E_ref(Q) — норма ошибки **моего** независимого конвейера 4-го порядка (`independent_reference/fd_ref.py`: веса Форнберга по 5 точкам, призрачные точки по чётности, односторонние 5-точечные шаблоны у краёв, Γ′ = D(Γ), M′ = D(M)) против точного ответа **на той же сетке, в той же норме и области**. Множитель 10: для одной и той же формальной точности константа ошибки зависит от выбора шаблона — центральный 5-точечный имеет главный член h⁴f⁽⁵⁾/30, полностью односторонний — h⁴f⁽⁵⁾/5 (отношение 6); композиция D(D f) против прямой второй производной даёт ещё множитель порядка единицы. Если модуль точнее — это не нарушение.
   - **Квадратуры** (M_ρ, M_flux, M_prop, M_int): `TOL_Q = 2·|E_trap| + FLOOR`, где E_trap — ошибка составной формулы трапеций на той же сетке для **точного** подынтегрального выражения (вычисляю сам). Контракт не фиксирует порядок квадратуры (вопрос К6), поэтому допускается худший разумный (2-й) порядок.
4. **Около θ = 0 и других нулей — только абсолютные допуски с физическим масштабом:** для Rθ± (безразмерно) масштаб 2 (значение в регулярном центре); для положения корня — масштаб M (Шварцшильд), 1/|H| (FLRW), ширина профиля w (синтетика). Относительных допусков со знаменателем ~0 нет нигде.
5. **Сходимость:** каждый численный тест — ≥ 3 сетки (обычно N = 100, 200, 400, 800; для D90 — 64…512), нормы L∞ и L2vol = (Σ_трапеции X²·4πR²A Δr)^{1/2} (ненормированная; рядом печатается нормированная на объём), отдельно области `center` (первые max(4, N/20) точек с R > 0), `bulk`, `outer` (последние 4) — те же определения, что в контракте §9. Наблюдаемый порядок p = ln(e₁/e₂)/ln(h₁/h₂) по последней паре сеток. Требование на порядок применяется, только если e_fine > 100·FLOOR (иначе «на уровне округления» = PASS). Положение корня — абсолютная ошибка в единицах физического масштаба.
6. **Классы сфер: «никогда не противоположный знак».** Для каждой точки и каждого ±: знак модуля s ∈ {+,0,−} должен совпадать с точным знаком или быть 0; если |Rθ±_exact| > δ = 3·TOL_TR(Rθ±), знак обязан совпадать. Разрешённый «0» при |Rθ±_exact| ≤ δ — проявление полосы τ (§7 контракта).
7. **Независимость от формы значений.** Поля знаков (`other_sign` и т.п.) принимаются как '+'/'−'/'-'/'0' или ±1/0 (контракт не фиксирует тип, вопрос К17). `Diagnostics` читается как атрибут или ключ.

## 2. Выводы из первых принципов, на которые опираются эталоны

Метрика ds² = −α²dt² + A²(dr + βdt)² + R²dΩ², K_ij = −(1/2α)(∂_tγ_ij − D_iβ_j − D_jβ_i).

- **K_B, U.** Γ^r_θθ = −RR′/A², β_r = A²β ⇒ D_θβ_θ = RR′β, K_θθ = −R(Ṙ − βR′)/α, K_B = −(Ṙ − βR′)/(αR). n^a = (1, −β)/α ⇒ n·∇R = (Ṙ − βR′)/α ⇒ **U = −R K_B** ✓ [F1].
- **³R.** Через собственную длину dl = A dr: ³R = 2(1 − R_l²)/R² − 4R_ll/R, R_l = Γ, R_ll = Γ′/A ✓ [F7] (проверка: сфера радиуса a даёт 6/a²).
- **𝓗.** K² − K_ijK^ij = (K_A + 2K_B)² − K_A² − 2K_B² = 4K_AK_B + 2K_B² ✓ [F8].
- **𝓜.** D_jK^j_r = K_A′ + (A′/A + 2R′/R)K_A − (A′/A)K_A − 2(R′/R)K_B; минус ∂_rK: −2K_B′ + 2(R′/R)(K_A − K_B) = 8πj_r ⇒ ✓ [F9] (знак j_i = −γ_i^a n^b T_ab, как у Baumgarte–Shapiro).
- **Проекции.** g^{cd}∂φ∂φ = −Π² + Φ² ⇒ ρ, S^r_r, S^θ_θ ✓ [F3, F5]; j_r = −Πφ′ ✓ [F4]. Физическая проверка знака: входящая волна φ = f(t + r) в плоском пространстве даёт j_r = −f′² < 0 (импульс внутрь).
- **M_MS, θ±** ✓ [F11, F12, F13]; совпадает с Bloomfield et al. 2015 (arXiv:1504.02071) ур. (13)/(19f) Γ² = 1 + U² − 2m/R и (54) Θ = (√2/R)(U + Γ) (их k^a нормирован на 1/√2 — знаки те же).
- **[F10] — ЗНАК.** Подставляя 16πρ = ³R + 4K_AK_B + 2K_B² − 𝓗 в 4πR²R′ρ и RUU′ = R²R′K_B² + R³K_BK_B′:
  M′ − 4πR²ρR′ = R³K_B[K_B′ − (R′/R)(K_A − K_B)] + (R²R′/4)𝓗, и −4πR²Uj_r = +4πR³K_Bj_r, откуда
  **𝓗_M = +(R²R′/4)·𝓗 + R³K_B·𝓜**, а не −(R²R′/4)𝓗, как в контракте. Контрольный пример: вакуум, K = 0, ρ → ρ + δρ: 𝓗 = −16πδρ, 𝓗_M = −4πR²R′δρ = +(R²R′/4)𝓗. Будет подтверждено символьно (RS1). → вопрос К1. **Тесты C60 проверяют обе невязки по определениям (§5 контракта), а не через тождество** — поэтому реализация, вычисляющая 𝓗_M через тождество с неверным знаком, будет поймана.
- **Высотный срез Минковского t = T(r).** n_a = −N(1, −T′), N = (1 − T′²)^{-1/2}, n^a = N(1, T′). A = 1/N, R = r, U = NT′, K_B = −NT′/r, K = −r⁻²(r²NT′)′ ⇒ K_A = −(NT′)′. Проверка: 𝓜 = 0, 𝓗 = 0 (с (NT′)² = N² − 1), M = 0; Rθ± = 2N(T′ ± 1) (знаки + и − при |T′| < 1). Частный случай T = √(r² + τ²) — гиперболоид (Milne): K_A = K_B = −1/τ.
- **PG:** A = 1, R = r, K_B = √(2M/r)/r, K_A = −K_B/2. **KS/IEF:** A = (1 + 2M/r)^{1/2}, K_B = 2M/(r²A), K_A = −2M(r + M)/(r³(1 + 2M/r)^{3/2}) (будет выведено из 4-метрики в RS2). Оба: M_MS ≡ M, Rθ₊ ∝ (1 − 2M/r).
- **Изотропный K = 0:** A = ψ², R = ψ²r, ψ = 1 + M/(2r); Γ = (1 − M/2r)/(1 + M/2r); горловина r = M/2, R = 2M; при r < M/2 Γ < 0.
- **FLRW:** R = ar, A = a, K_A = K_B = −H; M = H²R³/2; Rθ± = 2(HR ± 1).
- **Скаляр с потоком (данные в ареальной координате R = r).** Заданы φ(r), Π(r), K_B(r) (чётные). Импульсная связь ⇒ **K_A = K_B + rK_B′ − 4πrΠφ′** (алгебраически). Массовая функция M ≡ (r/2)(1 − A⁻² + r²K_B²) ⇒ A⁻² = 1 − 2M/r + r²K_B². Гамильтонова связь в массовой форме (при 𝓜 = 0 ⇔ 𝓗 = 0, R′ = 1):
  **M′ = 4πr²[½Π² + ½φ′²(1 + r²K_B²) + ½m²φ² + rK_BΠφ′] − 4πrφ′²·M**, M(0) = 0 — линейное ОДУ без деления на r. Интегрирую DOP853 (rtol 10⁻¹³) вместе с M_ρ,ref′ = 4πr²ρ, M_flux,ref′ = 4πr³K_BΠφ′ (U j_r = rK_BΠφ′).
- **FKG:** φ̈ + 3Hφ̇ + m²φ = 0, Ḣ = −4πφ̇², ȧ = aH; Фридман H² = (8π/3)ρ используется **только как диагностика** F_res = H² − 8πρ/3. На срезе ³R = 0, K-члены = 6H² ⇒ ожидаемая невязка модуля **𝓗 = 6·F_res**, 𝓜 = 0.

## 7. Критерии остановки (когда физическая интерпретация прекращается)

1. **Любой FAIL в S20–S25, F30–F32, M13 (классификация, корни, ah_candidate, статус)** ⇒ выходы `ah_candidate`, `outer_ah_candidate`, `status.geometry` не используются ни для каких утверждений о горизонтах; V1b/C3 перекрёстная проверка не проводится.
2. **Любой «разрешённый неверный знак» Rθ±** (п. 1.6) где-либо ⇒ оценки σ и полоса τ признаются ненадёжными; все маргинальные классы и `UNCERTAIN` не интерпретируются.
3. **Невязки на согласованных данных (M11, S21, X50) не сходятся с порядком ≥ 3 в bulk** ⇒ невязки и статус связей не используются как мера качества данных.
4. **FAIL X50/X51/X52 по M_flux или знаку потока** ⇒ M_int, M_flux, M_ρ не используются; допустимо только M_MS (если прошло X50 по M_MS).
5. **FAIL C60** (невязка нормирована в ноль, не локализована или VIOLATED не выставлен) ⇒ статус связей не используется.
6. **FAIL D90(b)** (σ не ограничивает ошибку) ⇒ любые утверждения «в пределах численной ошибки» от модуля не принимаются.
7. **FAIL R95** (сбой ⇒ `NO_TRAPPED_SPHERES` или data `OK`) ⇒ модуль непригоден для автоматического конвейера.
8. **Вопрос К1 (знак F10) не разрешён** ⇒ любые выводы из тождества F10 (напр. «𝓗_M мал ⇒ 𝓗 мал») не делаются.
9. **Сбой самопроверки эталона RS*** ⇒ зависимые тесты объявляются VOID (не PASS).
10. PASS всей матрицы **не** означает физической корректности PBH-выводов: модуль измеряет один срез; горизонт ЧД, образование PBH, пороги — вне объёма (контракт §7).

## 8. Вопросы к контракту (контракт не редактируется; предлагаемые решения)

- **К1 (ошибка знака, критично) — РЕШЁН в контракте 1.0 (Р1).** [F10]: должно быть 𝓗_M = **+**(R²R′/4)𝓗 + R³K_B𝓜 (вывод §2, пример вакуум + δρ). Найдено независимо (этот план v1.0, символьно RS1) и ролью derivation; контракт 1.0 исправлен. Тест C60 проверяет обе невязки по определениям, так что реализация, использующая тождество с неверным знаком, будет поймана.
- **К2 (пол полосы τ обращается в ноль).** τ_± = max(κσ, 10³ε(|U| + |Γ|)): на горловине/бифуркационной сфере |U| + |Γ| → 0; при аналитических производных (σ = 0) знаки Γ и «другого» расширения в корне решаются округлением ⇒ возможен ложный `ah_candidate` на минимальной поверхности (Γ = +10⁻¹⁸ «> 0»). Решение: пол 10³ε·max(1, |U| + |Γ|); условие «Γ > 0 в корне» и знак другого расширения — **разрешённые** (вне полосы), иначе `DEGENERATE`.
- **К3 (таксономия статусов).** [1.0: (b) решён явным приоритетом; (a) решён намерением «изолированная маргинальная точка с корнем DEGENERATE и не-trapped соседями ⇒ NO_TRAPPED_SPHERES + `marginal_present`»; (c) не решён.] **К3a′ (новое, противоречие в 1.0):** такая точка одновременно удовлетворяет первому условию `UNCERTAIN` («не отнесена к корню известного типа FUTURE_MOTS/PAST_MOTS и без trapped-соседей с обеих сторон»), а `UNCERTAIN` старше `NO_TRAPPED_SPHERES` по приоритету — разрешение для NO_TRAPPED_SPHERES буквально недостижимо. Решение: в условии UNCERTAIN исключить точки с корнем `DEGENERATE` и не-trapped соседями. Исходный текст: (a) Изолированная маргинальная/`DOUBLY_MARGINAL` точка между разрешёнными соседями (горловина в узле, точный ноль в узле) не попадает ни в один статус (`NO_TRAPPED_SPHERES` требует «все NORMAL/REVERSED/CENTER», `UNCERTAIN` — «без разрешённых знаков по соседству»). Решение: изолированные маргинальные точки учитываются через корни; статус определяется разрешёнными классами. (b) Нет явного приоритета: AH-кандидат + PAST_TRAPPED (PBH в FLRW), FUTURE_TRAPPED + PAST_TRAPPED и т.д. Решение: порядок UNDETERMINED > AH_CANDIDATE > FUTURE_TRAPPED_NO_AH_CANDIDATE > UNCERTAIN > PAST_TRAPPED_ONLY > NO_TRAPPED_SPHERES. (c) «0» из-за численной полосы (не точный ноль) делает `PAST_MARGINAL` ⇒ `PAST_TRAPPED_ONLY` для среза Минковского (M13). Решение: различать «маргинальный» и «неразрешённый»; неразрешённые ⇒ `UNCERTAIN`.
- **К4.** «θ₊ < 0 с внутренней и > 0 с внешней стороны»: брать ближайшую **разрешённую** точку с каждой стороны? Что если trapped-область уже одной ячейки? Решение: ближайшие разрешённые точки в пределах 3 узлов, иначе `DEGENERATE`.
- **К5 (сжимающийся FLRW).** Корень θ₊ при R = 1/|H| — `FUTURE_MOTS` с inner '+', outer '−' ⇒ `ah_candidate = False`, статус `FUTURE_TRAPPED_NO_AH_CANDIDATE`. Это следует из правил, но название статуса и пример («trapped-область до края сетки») читаются как «возможная PBH, горизонт не найден», тогда как это космологическое (crunch) trapping. Решение: добавить в корень поле `trapped_side ∈ {inner, outer}` и прямо записать, что `FUTURE_TRAPPED_NO_AH_CANDIDATE` не является свидетельством PBH; для внешней (по R) trapped-области без внешней границы — пометка `COSMOLOGICAL_OR_EDGE`.
- **К6.** Не задан порядок квадратуры M_ρ, M_flux, M_prop (и их σ). При трапециях M_int − M_MS = O(h²), что несовместимо с 4-м порядком M_MS. Решение: квадратура ≥ 4-го порядка (напр. интеграл кусочно-кубического интерполянта) + оценка ошибки.
- **К7.** L2vol: нормирована ли на объём (√(∫X²dV/∫dV)) или нет? Решение: указать; предлагаю нормированную (сравнимость между сетками/областями).
- **К8.** Недопустимый вход: исключение или возврат со статусом `INVALID_INPUT`? Решение: возврат (для конвейеров); исключение только при несовместимых формах массивов.
- **К9.** NaN только в материи: каков geometry-статус? (Геометрия от материи не зависит.) Решение: geometry вычисляется, constraints = `NOT_EVALUATED`/`INVALID`, data = `INVALID_INPUT`.
- **К10 — РЕШЁН в 1.0** (список [S1]–[S4] добавлен; [S1] = arXiv:2504.02600, [S2] = 1504.02071, [S3] = 1506.07122, [S4] = 1607.00199).
- **К11.** σ = |D⁽⁴⁾ − D⁽⁶⁾| поточечно имеет изолированные нули ⇒ ложные `VIOLATED`/ложно-разрешённые знаки в отдельных точках. Решение: σ_i = max по окну ±2 узла.
- **К12.** `matter=None` ⇒ связи не оцениваются даже для вакуума; вакуумные данные требуют явного `Projections(0,0,0,0)`. Решение: документировать или добавить `matter="vacuum"`.
- **К13.** Точный ноль в узле: «корень для каждой смены знака между соседними точками (или точного нуля)» допускает двойной подсчёт (i−1,i) и (i,i+1). Решение: один корень на точный ноль.
- **К14.** Метод/порядок экстраполяции `M_over_R3` в центр не задан. Решение: чётная полиномиальная экстраполяция по R² порядка ≥ 2.
- **К15.** Поточечный статус связей (§9) не выведен в поля §10 — нельзя проверить локализацию флагов. Решение: поле `constraint_flags` (массив строк).
- **К16.** «Знак другого расширения в корне» — как вычисляется (интерполяция в r*?) и с какой полосой τ? Решение: линейная интерполяция Rθ и τ в r*.
- **К17.** Тип `other_sign`, `inner_sign`, `outer_sign` не задан (строка '+'/'0'/'−' или int). Решение: строки '+', '0', '-' (ASCII).
- **К18** (1.0 уточнил распространение σ(𝓗), σ(𝓜), σ(𝓗_M) и «входные поля считаются точными», но случай аналитических производных не оговорён). При переданных `dA, dR, dKB` Γ′ и M′ всё равно численные (нужна R″), а контракт говорит «оценки ошибки = 0». Решение: σ = 0 только для величин, не требующих численных производных; σ(𝓗), σ(𝓗_M) — по-прежнему по D⁽⁴⁾ − D⁽⁶⁾.
- **К19.** R = 0 в не-центральной точке (center = "none") — `INVALID_INPUT`? Решение: да.
- **К21 (новое).** 1.0 §7: «(0,−) и (+,0) возможны только при Γ > 0; (−,0) и (0,+) — только при Γ < 0» — верно для точных нулей, но для «0» из полосы τ при |Γ| ≲ τ (около горловины) это утверждение не гарантировано; нужно указать, как классифицировать такие точки (предлагаю DOUBLY_MARGINAL, если |Γ| ≤ τ_Γ).
- **К22 (новое).** Тип `status.marginal_present` (bool) и его присутствие, когда статус не NO_TRAPPED_SPHERES, не заданы; предлагаю всегда присутствует (bool).
- **К23 (новое, найдено при отладке обвязки).** Порог `VIOLATED` |X| > κ_c σ(X) + 10³ε Σ|T_k| не содержит округления самих производных (~ε|f|·Σ|w| ~ ε|f|L/h на производную). На точных вакуумных данных, где все T_k = 0 (Минковский, FLRW-𝓜), σ = |D⁽⁴⁾ − D⁽⁶⁾| тоже на уровне округления и может случайно оказаться меньше |X|/κ_c ⇒ точные данные объявляются `VIOLATED`. Решение: добавить в порог член 10³ε·S_X·(L/h)^d (S_X — масштаб невязки, d — порядок производных) или использовать оконный максимум σ (К11). Тест M10/F30 требует «не VIOLATED» жёстко.
- **К24 (новое, существенно).** 1.0 §9: σ(𝓗) = 4|Γ|σ(Γ)/R² + 4σ(Γ′)/(AR), σ(𝓜) = σ(K_B′) + |K_A − K_B|σ(R′)/R, σ(𝓗_M) = σ(M′) + 4πR²|ρ|σ(R′) и «входные поля считаются точными» — но при `ScalarField` проекции ρ (через Φ²) и j_r = −Πφ′ сами содержат **численную** производную φ′. Её ошибка в σ не входит ⇒ на согласованных EKG-данных |𝓜| ≈ 4π|Π|·δφ′ ≫ κ_c σ(𝓜) у центра (на макете: |𝓜| ≈ 10⁻⁸ против σ ≈ 3·10⁻¹⁰ при N = 400) ⇒ ложный `VIOLATED`. Решение: σ(φ′) = |D⁽⁴⁾φ − D⁽⁶⁾φ|, σ(ρ) = |Φ|σ(φ′)/A, σ(j_r) = |Π|σ(φ′); добавить 16πσ(ρ) в σ(𝓗), 4πσ(j_r) в σ(𝓜), 4πR²(|R′|σ(ρ) + |U|σ(j_r)) в σ(𝓗_M). Тест X50 (N ≥ 200) требует «не VIOLATED» и укажет на К24 при провале; X52 (точные моменты) — контроль без этого эффекта.
- **К20.** ah-правило зависит от ориентации r: за горловиной (Γ < 0) внешняя граница trapped-области с нулём θ₋ никогда не кандидат. Для одного асимптотического конца это верно, но должно быть документировано.
