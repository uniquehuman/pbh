# independent_reference/ — эталоны независимой верификации (PBH-VERIFY-01)

Роль: независимая верификация. Код написан без чтения `src/`, `arch_A/`, `derivation/`, `derivation.md` и исходников `pbhgr`. **`sphdiag` здесь не импортируется** (кроме `harness_mock/`, который сам является макетом API, а не эталоном). Все формулы выведены в `verification_plan.md` §2 и проверены символьно из 4-метрики (`derive_sympy.py`).

Запуск самопроверки (из корня пилота): `python3 -m independent_reference.selfcheck` → `results/reference_selfcheck.json` (~45 с).

## Файлы и происхождение формул

| Файл | Что | Происхождение |
|---|---|---|
| `derive_sympy.py` | RS1: общая сферическая ADM-метрика α, β, A, R(t,r) → K_ij по определению K_ij = −(1/2α)(∂_tγ_ij − D_iβ_j − D_jβ_i); ³R из символов Кристоффеля; D_j(K^j_i − δ^j_iK); K = −∇_a n^a в 4D; T_ab скалярного поля и его проекции; M_MS из g^{ab}∂_aR∂_bR. RS2: точные срезы | собственный вывод (plan §2); сверка: Baumgarte & Shapiro 2010 (знаки ADM, j_i = −γ_i^a n^b T_ab); Bloomfield et al. 2015 (arXiv:1504.02071) ур. (13)/(19f) Γ² = 1 + U² − 2m/R, (54) Θ = (√2/R)(U + Γ) |
| `constraints_ref.py` | точные Γ, Γ′, U, M, M′, Rθ±, 𝓗, 𝓜, 𝓗_M из значений и **аналитических** производных (без конечных разностей); M′ по цепному правилу M′ = R′(1 − Γ² + U²)/2 + R(−ΓΓ′ + UU′), U′ = −R′K_B − RK_B′ | собственный вывод; F7–F13 подтверждены RS1 |
| `analytic.py` | `SymSlice`: срезы как выражения sympy по r; значения и производные через lambdify; значение в r = 0 — подстановка или (если 0/0) вычисление при r = 10⁻²⁵ в 80-значной арифметике (выражения аналитичны ⇒ ошибка O(10⁻²⁵)); корни Rθ± — сканирование + brentq; замена координаты r = f(x). Каталог: Минковский тривиальный; высотный срез t = T(r) (A = 1/N, K_B = −NT′/r, K_A = −(NT′)′, N = (1 − T′²)^{-1/2}); Milne в χ и в ареальной координате; Шварцшильд PG (K_B = √(2M/r)/r, K_A = −K_B/2), IEF/Kerr–Schild (A = √(1+2M/r), K_B = 2M/(r²A), K_A = −2M(r+M)/(r³(1+2M/r)^{3/2})), изотропный K = 0; FLRW (R = ar, A = a, K = −H, ρ = 3H²/8π); синтетический «PBH в FLRW» (только геометрия); полиномиальные срезы deg ≤ 4 (для точности 5-точечных шаблонов); изготовленный регулярный срез D90 | K_ij всех физических срезов выведены из 4-метрики в RS2 (не взяты из литературы); PG/KS/изотропный — стандартные метрики (напр. Baumgarte & Shapiro гл. 2) |
| `fkg.py` | собственный интегратор FKG: φ̈ + 3Hφ̇ + m²φ = 0, ȧ = aH, Ḣ = −4πφ̇² (DOP853, rtol 10⁻¹³); Фридман H² = 8πρ/3 **не навязывается** — F_res = H² − 8πρ/3 диагностика; вторая формулировка (H из связи) для перекрёстной проверки; среднее с окном Ханна по 4 периодам | стандарт (напр. Mukhanov 2005, гл. 5; 8πG = 8π); вложение в 3+1 — RS2 (FLRW) |
| `flux_data.py` | собственный решатель связей для EKG-данных с потоком в ареальной координате: задаются φ, Π, K_B (чётные гауссианы); K_A = K_B + rK_B′ − 4πrΠφ′ (импульсная связь, алгебраически); M′ = 4πr²[½Π² + ½φ′²(1 + r²K_B²) + ½m²φ² + rK_BΠφ′] − 4πrφ′²M (гамильтонова связь в массовой форме, линейное ОДУ без деления на r), A⁻² = 1 − 2M/r + r²K_B²; вместе интегрируются M_ρ,ref, M_flux,ref = ∫4πr³K_BΠφ′, M_prop,ref | собственный вывод (plan §2); эквивалентность массовой формы и 𝓗 = 0 при 𝓜 = 0 — тождество F10 (со знаком +), RS1 |
| `fd_ref.py` | собственный конвейер 4-го порядка (веса Форнберга по опубликованной рекурсии, Fornberg 1988, Math. Comp. 51, 699; призрачные точки по чётности; односторонние шаблоны у краёв) | используется **только** как масштаб допуска E_ref (plan §1.3), никогда как ожидаемое значение |
| `grids.py`, `norms.py` | сетки (равномерные, растянутые sinh/exp, vertex/cell/none), регионы §9 контракта, нормы L∞ и L2 с мерой 4πR²A dr, наблюдаемый порядок | собственный код |
| `selfcheck.py` | RS1–RS6 (plan §5) | — |
| `harness_mock/` | **макет API** для самопроверки обвязки тестов и мутационного теста (HS); не эталон | собственный код, мутации через `SPHDIAG_MOCK_MUTATION` |
