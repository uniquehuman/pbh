# PBH — коды для образования первичных чёрных дыр в эпоху ранней материи

Научные библиотеки вычислительной программы: могут ли первичные чёрные дыры астероидной массы (10¹⁹–10²⁰ г)
составлять всю тёмную материю, если они образовались, пока во Вселенной доминировало осциллирующее тяжёлое
скалярное поле — «пылевая» эпоха до разогрева. При таких массах поле совершает ≥ 10⁹ колебаний за хаббловское
время, поэтому оно моделируется бесстолкновительной материей: **система Эйнштейна–Власова** в сферической
симметрии и в полной 3D ОТО.

🌐 Результаты, графики, документы и данные: **https://pbh.ivliev.org** (русский и английский).

## Библиотеки

| Путь | Что это |
|---|---|
| [`pbhgr/pbhgr/`](pbhgr/pbhgr) | Python-пакет. `cosmo_ev` — сферический решатель Эйнштейна–Власова в проникающей под горизонт ареально-CMC калибровке с расширяющимся FLRW-внешним решением (полностью на связях; оболочки с радиальным и угловым моментом); уравнения — [`pbhgr/docs/areal_cmc_gauge.md`](pbhgr/docs/areal_cmc_gauge.md). `cosmo_id` — длинноволновые CMC начальные данные Yoo, Escrivà, Harada, Kohri (2026) на оболочках. `ltb` — точное решение Леметра–Толмена–Бонди с растущей модой (времена коллапса и захвата, M_AH(τ)). `profiles` — средние профили пиков BBKS для логнормальных спектров и профили с плоским ядром. `pm3d` — ньютоновский 3D particle-mesh для одного трёхосного пика на фоне Эйнштейна–де Ситтера. `spherical_ev` и вспомогательные модули — полярно-ареальный Эйнштейн–Власов с распадом поля в излучение, изолированные начальные данные, статические политропы. C-ядра — `pbhgr/csrc/`, тесты pytest — `pbhgr/tests/`. |
| [`pbhgr/grteclyn/PBHVlasov/`](pbhgr/grteclyn/PBHVlasov) | Модуль материи Власова (частицы) для 3D-кода численной ОТО **GRTeclyn** (AMReX): согласованное между уровнями AMR осаждение, геодезический пушер с собственным временем частиц, 1+log-калибровка с опорным профилем для космологического коллапса, ранний старт из данных Yoo et al., диагностика горизонта по лучам и сферам, примеры параметров. Проект: [`stage2_vlasov_design.md`](pbhgr/docs/stage2_vlasov_design.md), [`stage1b_design.md`](pbhgr/docs/stage1b_design.md) (англ.). |
| [`pbhgr/grchombo/PBHCosmo/`](pbhgr/grchombo/PBHCosmo) | Пример для **GRChombo**: коллапс пика LTB-типа в скалярном поле в расширяющемся боксе — начальные данные LTB, калибровка с опорным профилем, разметка сфер для AMR. |
| [`pbhgr/scripts/`](pbhgr/scripts) | Драйверы: `v1_ladder.py` (лестница валидации и рабочие расчёты `cosmo_ev`), `v1_static_test.py`, `pm3d_peak.py`, `ellipsoidal_collapse.py` (Бонд–Майерс). `scripts/grchombo/`: скрипт сборки GRChombo/GRTeclyn, генераторы начальных данных и параметров 3D-модулей (`ltb_to_grchombo.py`, `stage1b_params.py`), сравнение 3D с LTB и 1D, диагностика контрольных точек. |
| [`sphdiag/`](sphdiag) | Диагностика сферически-симметричных 3+1-срезов для любой материи (скалярное поле, моменты Власова, заданный тензор энергии-импульса): невязки связей, масса Misner–Sharp, расширения световых лучей θ±, классы сфер и кандидаты видимого горизонта — с оценками численной ошибки и флагами пригодности. Только измеряет: не эволюционирует и не решает связи. Спецификация формул — [`physics_contract.md`](sphdiag/physics_contract.md), символьный вывод — [`derivation.md`](sphdiag/derivation.md). |

История коммитов каждой библиотеки сохранена (в пределах этих путей).

## Быстрый старт

```bash
cd pbhgr
make                                            # собирает C-ядро pbhgr/_kernels.so
make test                                       # pytest (длинные тесты: --runslow)
python3 scripts/v1_ladder.py flrw --K 1000      # проверка на однородном FLRW
python3 scripts/v1_ladder.py ltb --mu 0.3 --tend 6.5 --K 2000 --n 4 --stretch 4 --out runs/v1   # пик LTB

cd ../sphdiag
PYTHONPATH=src python3 -m pytest tests/dev      # 106 тестов, несколько секунд
```

Python ≥ 3.12 с numpy и scipy (`pbhgr` также использует psutil, pyyaml, h5py) и компилятор C. Единицы G = c = 1;
для профиля Yoo k = 1, H_i = 5, t_H = 100√6, M_H = 0,75 t_H.

3D-модули компилируются внутри исходников GRTeclyn и GRChombo: см.
[`pbhgr/scripts/grchombo/build_grchombo_ax102.sh`](pbhgr/scripts/grchombo/build_grchombo_ax102.sh) и
[`pbhgr/docs/grchombo_ax102.md`](pbhgr/docs/grchombo_ax102.md). Параметры 3D-расчётов с ранним стартом
генерирует `pbhgr/scripts/grchombo/stage1b_params.py`.

## Что показали эти коды (октябрь 2026)

- Сферическая ОТО + Власов, холодный случай, сходимость достигнута: μ_th(100 t_H) ≈ 0,039,
  μ_th(300 t_H) ≈ 0,019, μ_th(1000 t_H) ≈ 0,0086.
- 3D ОТО с PBHVlasov, сферический пик: рост горизонта совпадает с точным LTB и 1D-кодом в пределах
  ±0,01 t_C(0) на 0,1–0,6 M_H.
- 3D ОТО с PBHVlasov, эллиптичность e = 0,2 (предварительно, см. оговорку): при μ = 0,3 горизонт ≈ 1 M_H при
  собственном времени материи τ = 2,09 t_C(0); при μ = 0,1 — горизонт 0,35–0,56 M_H при τ = 2,44 t_C(0).

**Оговорка / известная проблема (10 октября 2026):** в 3D-расчётах с ранним стартом (`pbh_vlasov.init = yoo`)
на гранях самого мелкого уровня адаптивной сетки в сверхгоризонтной фазе развивается неустойчивость. Результаты
для e = 0,2 содержат пока не оценённую ошибку порядка 10 % в бесследовой внешней кривизне Ã и предварительны;
проверки e = 0 против LTB не затронуты. Подробности — запись журнала за 10 октября: https://pbh.ivliev.org/ru/log/
